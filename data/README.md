# Data

This directory holds the HDF5 files used for model training and evaluation. Note that the clinical data behind these files are restricted; only the waveform databases are openly available (see below).

## Samples tables (`*_samples_pre.h5`)

Each samples table is a pandas DataFrame (HDF key `"table"`) with one row per sample and metadata columns such as `sample_id`, `subject_id`, `ecg_time` and split assignments (`*_split`).

* **`mimic4_samples_pre.h5`** — Base samples table for MIMIC-IV. Read by `prepare_mimic4.ipynb`, which enriches it with patient demographics and laboratory values from the MIMIC-IV clinical database, producing `mimic4_samples.h5`. `mimic4_samples_pre.h5` was generated from MIMIC-IV-ECG and thus does not contain restricted information.
* **`mimic3_samples_pre.h5`** — Base samples table for MIMIC-III. Read by `prepare_mimic3.ipynb`, which enriches it with demographics and laboratory values from the MIMIC-III clinical database, producing `mimic3_samples.h5`. `mimic3_samples_pre.h5` was generated from MIMIC-III-WDB (matched subset) and thus does not contain restricted information.

## Signal files (`*_signals.h5`)

Each signal file stores the ECG waveforms, keyed by `sample_id`, together with the corresponding samples table.

* **`mimic3_signals.h5`** — Single-lead (lead II) ECG waveforms extracted from [**MIMIC-III-WDB (matched subset)**](https://physionet.org/content/mimic3wdb-matched/1.0/) at 125 Hz. This file is *not* generated by any notebook in this repository; it is used as a preprocessed input for external validation on MIMIC-III (`evaluate.ipynb`).
